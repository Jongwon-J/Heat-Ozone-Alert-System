# 재현 방법 (최소)

## 필요한 파일 위치
- `data/ASOS/ASOS_TIM_*.csv`, `data/Ozone/*/*.xlsx` — 기상청/에어코리아 원본
- `data/HeatIllness/온열질환 발생 신고 데이터(2011-2025).csv` — 질병관리청 원본
- `output/_cache_ozone_seoul_may_sep.parquet` — 오존 캐시(없으면 `merge_and_scatter.load_ozone()`이 xlsx부터 새로 만듦, 느림)
- `src/gate1_analysis.py`, `apparent_temperature.py`, `merge_and_scatter.py` — 공통 계산 함수(수정 금지)

## 실행 순서

1. `python3 src/run_label11_18.py`
   기대 출력 한 줄: `11-18,0,33.00,158.25,49.81,1.25,7.75,2.19,34.25,166.00,52.00,...` (라벨11~18 행, m3_stmedian_D=52.00)

2. `python3 src/run_week6.py`
   기대 출력 한 줄: `0.09 행 TypeA_연평균시간=49.8125 TypeB_연평균시간=2.1875`

3. `python3 src/run_week7.py`
   기대 출력 한 줄: `[2018 포함] 매칭 쌍 55개 ... p=0.189632`

4. `python3 src/make_heatmaps.py`
   기대 출력 한 줄: `저장: .../output/6주차_시각별_히트맵_사각지대시간.png`

5. `docker compose up -d` (프로젝트 루트에서)
   기대 출력 한 줄: `Container hufsh-up-airflow-scheduler-1  Started` → healthy

6. `docker compose exec airflow-scheduler airflow dags trigger gate1_label11_18`
   기대 출력 한 줄: `airflow dags list-runs -d gate1_label11_18` 의 state 열이 `success`

7. `pytest tests/` (호스트) 와 `docker compose exec airflow-scheduler pytest /opt/project/tests` (컨테이너)
   기대 출력 한 줄: 호스트 `8 passed, 1 skipped`, 컨테이너 `9 passed`
