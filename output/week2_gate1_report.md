## A. 지난 결과 중 불명확했던 3가지

### A-1. 기온·습도 QC플래그 = 1(오류) 처리

- 코드(`src/merge_and_scatter.py` `load_asos`): `QC플래그 == 1`이면 해당 기온/습도를 **NaN(결측)으로 바꾸고**, 이후 `merged[merged['AT'].notna()]`에서 체감온도가 NaN인 시각은 **병합 결과에서 제외**된다. 즉 '결측 처리 → 결과적으로 제외'.
- **실제 영향은 0행이다.** 시즌(5~9월, ASOS 32,784행) QC분포: 기온 QC = 공란 30,571 / 0 = 2,213 / **1 = 0건 / 9 = 0건**, 습도도 동일 양상(공란 30,600 / 0 = 2,184). 값 결측도 0건, 2018-05~2025-09 시각 누락도 0건. (QC 공란은 정상으로 취급.)

### A-2. 에어코리아 datetime 역할 컬럼

- 원본 컬럼명은 **`측정일시`** (정수 `YYYYMMDDHH`, HH = 01~24, 예: `2022070101`). 별도의 날짜/시간 컬럼은 없다. 코드에서 `datetime`으로 rename하고 24시는 익일 00:00으로 변환한다.
- xlsx 100개 전체의 헤더 동일 확인(`지역, 망, 측정소코드, 측정소명, 측정일시, SO2, CO, O3, NO2, PM10, PM25, 주소`). 예외 1개: `2022년 4월.xlsx`는 값이 없는 빈 컬럼 2개가 더 있음(영향 없음).

### B-3. 결론 (어느 정렬이 맞는지는 정하지 않음)

- 세 결과의 차이는 **−1h: 약 +6~9%, +1h: 약 −13~14%** 수준이다(위 변화율). 규모는 비슷하고, 방식 2·3의 Gate 등급은 세 정렬 모두 **진행**으로 같다.
- 그러나 **방식 1(측정소 평균)은 등급이 바뀔 수 있다**: 원본 34.2h·−1h 36.4h는 진행이지만 **+1h는 29.6h로 30h 미만(재판정)**. "영향 없음"이라고 결론짓기 어렵다 — 방식 1을 쓴다면 이 정렬 문제가 판정을 좌우할 수 있다.
- 어느 쪽이 맞는지는 **에어코리아 확정자료 정의(공식 문서)로 확인해야** 하며, 여기서는 임의로 정하지 않았다. 원본(0h)을 기본으로 표시했을 뿐, 그것이 옳다는 판단은 아니다.

## 가정과 미확정 사항 (윤서 확인 필요)

1. **타임스탬프 정렬**: 원본에 정의 없음(B). 확정 전에는 방식 1의 판정을 최종으로 쓰기 어렵다.

3. **특보일 정의**: '2일 연속 충족한 구간의 모든 날'로 재현. '2일째부터'로 바꾸면 방식 1 A+B 35.0h(D-4).
4. **집계 방식 미선택**: C의 3가지 중 무엇을 Gate 1에 쓸지는 결정하지 않았다(제안 파일 참조). 결과를 이미 본 상태에서 정하는 것이므로, 선택 근거는 결과와 무관한 논리(예: 노출 단위)로 기록하는 것이 7절 원칙('결과 확인 후 기준 변경 금지')에 부합한다.
5. **2026년 미포함**: 5~9월 오존 자료가 없어 8시즌(2018~2025) 평균. 2020~2021 코로나 기간 제외 민감도는 아직 안 함(정의문서 6주차 계획).
6. Type A는 '특보 미충족일'이면 그날 체감온도가 33℃를 넘는 시간이 있어도 포함한다(정의문서 6절 그대로 구현).
