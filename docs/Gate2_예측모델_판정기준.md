# Gate 2 ② 예측모델 판정 기준 (사전 등록 문서)

- 프로젝트: 이동노동자 폭염·대기질 복합리스크 평가 및 대응 시스템 (팀 씨앗, HUFS H-UP)
- 문서 상태: **초안 v1 — 윤서 씨 확인 후 확정(동결)**
- 작성일: 2026-11-14
- 이 문서의 역할: 모델을 만들기 **전에** "무엇을, 어떻게 비교해서, 어떤 결과가 나오면 통과인지"를 못 박아 둔다. 결과를 본 뒤 기준을 바꾸면 결과를 끼워 맞춘 것이 되기 때문이다(중간발표 30시간 기준에 근거 기록이 없었던 문제를 반복하지 않기 위함).

## 0. 먼저 이해할 것: "관측 날씨로 공부하고, 예보 날씨로 시험 본다" 문제

### 쉬운 설명
모델은 "내일 오후 오존이 높을지"를 맞히기 위해 **내일 날씨**(기온, 구름, 바람)를 입력으로 쓴다. 문제는 그 날씨를 어디서 가져오느냐다.

| 구분 | 내일 날씨를 어디서? | 정확도 |
|---|---|---|
| 학습할 때 (2018–2024 과거 자료) | 그날 **실제로 관측된** 날씨 | 100% 정확 (이미 일어난 일) |
| 실제 운영할 때 (서비스) | 전날 저녁 기상청 **예보** | 틀릴 수 있음 |

비유하면, **문제집 해설(정답 날씨)을 보면서 연습한 학생이 실전 시험에선 해설 없이(예보만 보고) 푸는 상황**이다. 연습 점수가 실전 점수보다 높게 나올 수밖에 없다. 예컨대 예보는 "맑음"이었는데 실제로 구름이 껴서 오존이 안 올랐다면, 관측 날씨로 채점한 모델은 맞힌 것으로 나오지만 실제 운영에서는 틀린다.

### 우리의 결정
- 과거 예보 자료를 날짜별로 확보·검증하는 일은 남은 기간(12/19까지)에 비해 부담이 크므로, **학습과 2025년 판정 모두 관측 날씨로 한다.**
- 대신 결과를 보고할 때 반드시 이렇게 쓴다: **"이 성능은 내일 날씨 예보가 완벽하다고 가정한 상한값이다. 실제 운영 성능은 이보다 낮을 수 있다."**
- 과거 단기예보 자료를 확보할 수 있으면(확보 가능 여부는 아직 확인하지 않음) 2025년을 예보 날씨로 한 번 더 채점해 참고값으로 붙인다. 판정 자체는 바꾸지 않는다.
- 비교 대상인 기준선(지속성 예보, 1.4절)은 날씨를 쓰지 않으므로 이 문제가 **모델 쪽에만 유리하게** 작용한다는 점도 함께 적는다.

## 1. 예측 문제 정의

### 1.1 무엇을 예측하나
- **발표 시각**: 예보일 D의 전날(D-1) **19:00** (1.3절 참고 — 결정 필요 항목)
- **대상 시간**: D일 근무시간 라벨 11~18 (구간 끝 표기, 라벨 HH = (HH-1)시~HH시 평균. 실제 10~18시)
- **대상 지점**: 서울 도시대기측정소 25개 (구별 1개)
- **예측값**: 각 지점·시간의 **오존 농도(ppm)** — 회귀 모델
- **판정용 사건**: 오존 1시간 평균 **≥ 0.091 ppm** (대기질 예보 '나쁨' 하한)
- 평가 단위: 지점 × 시간 (한 해 5~9월 기준 약 25 × 8 × 153 ≈ 30,600행)

> 왜 확률(분류)이 아니라 농도(회귀)인가: 분류 모델의 확률 기준선(θ)은 재학습하면 의미가 바뀌어 2024년에 고른 θ를 2025년에 그대로 쓰기 어렵다. 농도는 단위(ppm)가 고정돼 있어 θ를 옮겨 쓰기 안전하고, 기준선(지속성 예보)도 농도이므로 두 방법을 똑같은 방식으로 다룰 수 있다. (검토 기록 R2)

### 1.2 데이터 분할 (시간 순, 섞지 않음)

| 구간 | 연도 | 용도 |
|---|---|---|
| 학습 | 2018–2023 | 모델 학습 |
| 검증 | 2024 | 하이퍼파라미터·판정 기준값 θ 선택 (여러 번 봐도 됨) |
| 시험 | **2025** | **판정, 단 한 번만** |
| 제외 | 2026 | 이번 판정에 쓰지 않음 |

- 2025년 자료는 파일로 만들어 두는 것까지는 허용하지만, **이 문서가 동결되기 전에는 사건 비율·분포 등 어떤 통계도 보지 않는다.** (현재까지 2025년 수치는 확인하지 않았음)
- 무작위 분할(랜덤 셔플)은 금지. 같은 날의 시간들이 학습과 시험에 나뉘어 들어가면 정답이 새어 나간다.

### 1.3 발표 시각과 자료 가용성 — **결정 필요**
19:00에 발표한다면 그 순간 손에 있는 자료만 쓸 수 있다.

| 자료 | 19:00 발표 시 사용 가능 범위 |
|---|---|
| 에어코리아 오존·NO₂ | D-1 라벨 18 (17~18시)까지 |
| 기상청 단기예보 | D-1 17시 발표분 (D일 예보) |
| ASOS/AWS 관측 | D-1 18시까지 |

- **18:00 발표안**의 문제: 에어코리아 라벨 18 값이 18:00 정각에 공개된다는 보장이 없다. 18:00을 고집하면 D-1 자료를 라벨 17에서 끊어야 하고, 지속성 기준선도 "어제 같은 시각"이 아닌 값을 써야 해서 비교가 꼬인다.
- **권고: 19:00 발표.** 퇴근 전후 알림으로도 자연스럽고 자료 시점이 깔끔하다.
- 추가 한계: 운영 시 쓰는 에어코리아 실시간 자료는 **미확정 자료**, 학습에 쓴 과거 자료는 **확정 자료**다. 둘이 조금 다를 수 있음을 한계에 적는다.

### 1.4 비교 대상 세 가지

| 이름 | 내용 | 역할 |
|---|---|---|
| **기준선 (지속성 예보)** | "내일 HH시 오존 = 오늘 HH시 오존" | 넘어야 할 최소선 |
| **모델 A** | XGBoost 회귀, 2.1절 입력 | **판정 대상** |
| **모델 B** | 모델 A + 예측 일사량 | A보다 나은지 추가 확인 |

- 지속성 예보가 기준선인 이유: 오존 고농도는 여러 날 이어지는 경우가 많아 "어제와 같다"만으로도 꽤 맞는다. 이것도 못 넘으면 모델을 만든 의미가 없다.

## 2. 모델 입력과 학습 규칙

### 2.1 입력 변수 (이 목록 밖의 변수는 추가 금지 — 추가하려면 문서 개정 기록을 남김)

| 묶음 | 변수 | 비고 |
|---|---|---|
| 전날 대기질 | 같은 지점 D-1 라벨 11~18 오존, D-1 일최고 오존, D-1 라벨 18 오존, D-1 라벨 11~18 NO₂ 평균, D-3~D-1 일최고 오존 평균 | 모두 D-1 라벨 18 이전 |
| 내일 날씨 (관측으로 대체, 0장) | 구별 AWS 기온(시간별·일최고), 하늘상태 3범주(전운량 0–5 맑음 / 6–8 구름많음 / 9–10 흐림, ASOS 108), 풍속, 습도(ASOS 108), 강수 여부 | 운영 시 단기예보로 교체 |
| 일사 관련 | 맑은 하늘 이론 일사량(계산값), D-1 관측 일사 합(ASOS 108) | 단기예보엔 일사량이 없음 |
| 달력·지점 | 월, 연중일(sin/cos), 요일·공휴일 여부, 시간 라벨, 지점 ID | 요일은 NO₂ 배출 차이 반영 |
| **모델 B만** | D일 시간별 예측 일사량 | 2.3절 |

- **사용 금지**: D일 에어코리아 값 일체(예: "1~3시간 전 오존"), D-1 라벨 19 이후 값, 2025년 자료로 만든 어떤 통계.
- 습도: AWS 11개 지점은 2018–2021년 습도가 없으므로 ASOS 108 습도를 공통으로 쓴다(윤서 씨와 최종 확인 필요).

### 2.2 학습 절차
1. 하이퍼파라미터 후보는 미리 정한 격자만 탐색: `max_depth ∈ {3, 5, 7}`, `learning_rate ∈ {0.03, 0.1}`, `min_child_weight ∈ {1, 5}`, `subsample = 0.8`, `colsample_bytree = 0.8`, 트리 수는 2024 검증 RMSE 기준 조기 종료(최대 2000, 인내 100). 난수 시드 42 고정.
2. 2018–2023으로 학습 → 2024로 위 격자 중 최적 조합과 트리 수 결정.
3. 판정 기준값 θ 선택 (2.4절).
4. **확정된 설정으로 2018–2024 전체를 다시 학습**(트리 수는 2번에서 정한 값 그대로) → 이 모델로 2025년을 단 한 번 예측.
5. 참고용으로 "2018–2023만 학습한 모델"의 2025 결과도 함께 보고(판정에는 쓰지 않음).

### 2.3 모델 B의 일사량 예측 (교차 예측)
- 일사량 예측 모델(하늘상태·이론 일사량·D-1 일사·달력 → D일 시간별 일사)을 따로 만든다.
- 학습 구간의 일사 예측값은 **연도 단위 교차 예측**으로 만든다: 2018년 값은 2018년을 뺀 나머지 해로 학습한 모델이 예측. 이렇게 해야 모델 B가 "정답에 가까운 일사"를 보고 학습하는 누수를 막는다.
- 2024·2025년 값은 그 이전 연도로만 학습한 일사 모델로 예측.

### 2.4 판정 기준값 θ 선택 (기준선과 모델 모두 동일한 방식)
- 예측 농도 ≥ θ 이면 "고농도 예보".
- θ 후보: 0.060 ~ 0.120 ppm, 0.001 간격.
- **2024 검증 자료에서 CSI가 최대인 θ**를 고른다. 기준선도 똑같이 2024에서 고른다(기준선에 0.091을 그대로 강요하면 모델만 조정 이득을 봐서 불공정).
- 고른 θ는 2025 판정에 그대로 쓴다. 2025 결과를 본 뒤 θ 변경 금지.

## 3. 판정 규칙 (엄격 기준)

### 3.1 주 지표: CSI (Critical Success Index)
```
CSI = 적중 / (적중 + 놓침 + 헛경보)
```
- 적중: 예보 O, 실제 O / 놓침: 예보 X, 실제 O / 헛경보: 예보 O, 실제 X
- "둘 다 아님"은 계산에 안 들어간다. 고농도가 전체의 3~12%뿐이라 정확도(Accuracy)는 "항상 아니라고 하기"만으로 90% 이상이 나와 쓸모가 없기 때문이다.

### 3.2 공통 평가 행
- 2025년 5~9월, 25개 지점, 라벨 11~18 중 **실제 관측값과 기준선 입력(D-1 같은 시각 값)이 모두 있는 행**만 쓴다.
- 기준선·모델 A·모델 B 모두 정확히 같은 행으로 채점한다.
- 제외된 행 수와 비율을 보고서에 적는다.

### 3.3 통과 조건 — 블록 부트스트랩
차이 `ΔCSI = CSI(모델 A) − CSI(기준선)`이 우연이 아닌지 확인한다.

1. 2025년 평가 기간을 **날짜 블록**으로 나눈다. 한 블록 = 그날의 25개 지점 × 8시간 전부(같은 날 지점끼리는 날씨를 공유해 독립이 아니기 때문).
2. 블록을 복원 추출로 다시 뽑아 같은 길이의 가상 시즌을 만들고 ΔCSI를 계산. 이를 **B = 2,000회** 반복(시드 20251231 고정).
3. 2,000개 ΔCSI의 2.5% ~ 97.5% 구간 = 95% 신뢰구간.
4. 이를 **두 가지 블록 길이로 모두** 수행:
   - (가) 1일 블록
   - (나) 연속 7일 이동 블록 (오존 고농도가 며칠씩 이어지는 점을 반영 — 1일 블록만 쓰면 구간이 실제보다 좁게 나올 수 있음)

**통과: (가)와 (나) 모두에서 ΔCSI 95% 신뢰구간 하한 > 0**
→ "모델 A가 지속성 예보보다 낫다"고 말할 수 있다. 하나라도 하한 ≤ 0이면 **불통과**.

> 왜 "점수 차가 0.05 이상" 같은 기준을 두지 않았나: 0.05라는 숫자에는 근거가 없다(30시간 기준과 같은 문제). 대신 "차이가 우연이 아니다"를 통계적으로 확인하는 쪽을 택했고, 블록 길이 두 가지를 모두 통과하게 해서 엄격하게 만들었다.

### 3.4 모델 B 채택 규칙 (A가 통과했을 때만 검사)
- 같은 방식으로 `ΔCSI = CSI(B) − CSI(A)`를 (가)(나) 모두 검사.
- 두 하한 모두 > 0 → 모델 B 채택. 아니면 **모델 A 유지** (단순한 쪽을 택함).
- A가 불통과면 B는 판정 대상이 아니다(참고 수치로만 보고). 순서를 정해 검사하므로 여러 번 비교해서 우연히 통과하는 문제를 피한다.

### 3.5 함께 보고할 진단 지표 (판정에는 쓰지 않음)
- POD(탐지율) = 적중/(적중+놓침), FAR(헛경보율) = 헛경보/(적중+헛경보), 빈도편향 = (적중+헛경보)/(적중+놓침)
- MAE(농도 평균절대오차, ppm)
- 월별(5~9월)·지점별·시간 라벨별 CSI
- 2025년 실제 고농도 비율 (시험 개봉 후 처음 공개)
- 모델 A의 2018–2023 학습판 결과(2.2절 5번), 관측 대신 예보 날씨 채점 결과(0장, 가능할 때만)

### 3.6 판정 결과별 다음 행동

| 결과 | 행동 |
|---|---|
| A 통과 | 웹 지도에 "내일 오후 오존 고농도 가능" 표시 기능 포함, 성능은 상한값임을 명시 |
| A 불통과 | **익일 예측 기능 제외.** 도구는 실시간 관측 + 기상청 폭염 예보 + 사각지대 이력 표시로 진행. 불통과 결과와 원인 분석을 그대로 보고(부정적 결과도 결과) |
| 판정 불가 | 2025 확정 자료 미공개, 평가 행이 크게 부족 등 → 사유 기록 후 교수님과 상의 |

- θ를 고르는 2024년이 다른 해의 2~4배 수준으로 고농도가 많다. 2025년이 2024년과 비슷할지, 예년 수준일지는 모른다.
- 영향: CSI는 사건이 드물수록 낮게 나오는 경향이 있다. 그래서 **모델 점수 하나만 보면 안 되고**, 같은 해 같은 행에서 기준선과의 차이(ΔCSI)로 판정한다. 기준선도 같은 불리함을 겪으므로 공정하다.
- 2025년 비율은 판정 후 보고서에 함께 적고, 해석할 때 이 차이를 고려한다.

## 5. 누수 점검표 (시험 개봉 전 전부 체크)

- [ ] D일 에어코리아 값이 입력에 하나도 없다
- [ ] 모든 대기질 입력의 최신 시각이 D-1 라벨 18 이하다 (코드로 검사)
- [ ] 이동평균·지연 변수가 미래 값을 쓰지 않는다 (shift 방향 확인)
- [ ] 결측 대체·스케일링 기준값을 학습 구간에서만 계산했다
- [ ] 분할이 연도 단위이고 섞지 않았다
- [ ] 모델 B 일사 예측값이 연도 교차 예측으로 만들어졌다
- [ ] 하이퍼파라미터·θ를 2024에서만 골랐다
- [ ] 2025년 통계를 열람한 기록이 없다
- [ ] 이 문서와 코드의 해시(SHA-256)·날짜를 동결 기록에 남겼다

## 6. 동결과 개봉 절차
1. 윤서 씨 확인 → 1.3절(발표 시각)·2.1절(습도 대체) 결정 반영 → **v1.0 동결**.
2. 동결 기록: 날짜, 이 파일의 SHA-256, 학습 코드 파일들의 SHA-256을 `docs/Gate2_동결기록.txt`에 남긴다.
3. 학습·검증 완료 후 누수 점검표 통과 → 2025 시험 **1회** 실행 → 결과를 수정 없이 저장.
4. 개봉 후 기준 변경은 금지. 부득이한 변경(코드 버그 등)은 "개봉 후 변경" 항목으로 사유와 변경 전·후 결과를 모두 보고.

## 7. 결과 해설 계획 (공부용 — 결과가 나온 뒤 작성)
결과가 나오면 "왜 그 점수가 나왔는지"를 아래 순서로 정리한다.
1. **어떤 입력이 가장 크게 작용했나**: SHAP 값으로 변수별 기여도 확인 (예: 전날 오존, 내일 기온, 하늘상태 중 무엇이 주도했는지)
2. **어디서 기준선을 이겼고 어디서 졌나**: 고농도가 시작되는 첫날(지속성 예보가 반드시 놓치는 날)과 끝나는 날(지속성 예보가 헛경보를 내는 날)에서 비교
3. **월·지점·시간대별 차이**와 그 대기과학적 이유 (일사·기온·NO₂ 적정 효과 — 윤서 씨 전공 설명과 연결)
4. **대표 사례 3~5일**: 모델이 맞힌 날, 틀린 날의 실제 날씨와 오존 곡선
5. 관측 날씨로 채점한 상한값이 실제 운영에서 얼마나 떨어질 수 있는지 논의
