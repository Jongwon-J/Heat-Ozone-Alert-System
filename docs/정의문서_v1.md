## 2. 체감온도 산출식

**출처** 기상자료개방포털 > 기후통계분석 > 응용기상분석 > 체감온도
**적용** 여름철(5~9월), 2022.6.2 개정식

```
체감온도 = -0.2442 + 0.55399·Tw + 0.45535·Ta
           - 0.0022·Tw² + 0.00278·Tw·Ta + 3.0

  Ta = 기온(℃)
  Tw = 습구온도(℃)
```

**습구온도 (Stull 추정식)**

```
Tw = Ta·ATAN[0.151977·√(RH + 8.313659)]
     + ATAN(Ta + RH)
     - ATAN(RH - 1.67633)
     + 0.00391838·RH^1.5·ATAN(0.023101·RH)
     - 4.686035

  RH = 상대습도(%)
```

### 주의사항

- **ATAN은 라디안 기준이다.** degrees 변환 금지. 파이썬 `math.atan()` / `np.arctan()`, 엑셀 `ATAN()` 그대로 사용.
- 포털은 **일 최고 체감온도**만 제공한다. 시간별 값은 위 식으로 직접 계산한다.
- 2022.6.2 이전 구간은 구 산출식 기준이다. **전 기간을 현 식으로 통일 계산**한다.
- 포털 제공값은 관측 기반이므로 기상청 날씨누리의 생활기상지수(예보값)와는 차이가 있다.
- 겨울철 산출식은 사용하지 않는다 (분석 범위 5~9월).

## 4. 오존 임계값

**기본값** 0.09 ppm (1시간 평균)
**민감도 분석** 0.06 / 0.08 / 0.09 / 0.10 / 0.12 전수

### 근거

**오존경보제** (대기환경보전법)

| 단계 | 기준 (1시간 평균) |
|---|---|
| 주의보 | 0.12 ppm 이상 |
| 경보 | 0.3 ppm 이상 |
| 중대경보 | 0.5 ppm 이상 |

해제: 주의보는 0.1 ppm 미만, 경보는 0.3 미만이면 주의보로 하향
출처: 에어코리아 오존경보제

**대기환경기준** (환경정책기본법 시행령 별표1, 2021.7)

| 물질 | 기준 |
|---|---|
| 오존 | 8시간 평균 0.06 ppm 이하 / 1시간 평균 0.1 ppm 이하 |
| PM2.5 | 연간 15㎍/㎥ / 24시간 35㎍/㎥ |
| PM10 | 연간 50㎍/㎥ / 24시간 100㎍/㎥ |
| NO₂ | 연간 0.03 / 24시간 0.06 / 1시간 0.10 ppm |

출처: 에어코리아 대기환경기준

### 0.09를 기본값으로 정한 이유

환경기준 1시간 0.1 ppm과 8시간 0.06 ppm 사이 값으로 설정했다. 주의보 기준인 0.12 ppm은 발령 빈도가 낮아 분석에 필요한 표본을 확보하기 어렵다. 다만 이 값은 연구자가 설정한 것이므로, 0.06~0.12 범위 전수로 민감도 분석을 수행하여 결과의 견고성을 확인한다.

## 5. 폭염특보 판정

**방식** 발령 이력이 아닌 '기준 충족 여부'를 재현
**기준** 일 최고 체감온도 33℃ 이상이 2일 연속

### 근거 (기상청, 2026.6.1 시행)

| 단계 | 기준 |
|---|---|
| 주의보 | 일 최고 체감온도 33℃ 이상 2일 이상 지속 예상 |
| 경보 | 일 최고 체감온도 35℃ 이상 2일 이상 지속 예상 |
| 중대경보 | 폭염경보 지역에서 체감 38℃ 또는 기온 39℃ 이상이 하루만 예상돼도 발표 |

출처: 기상청 「18년 만에 폭염특보 개편, 22년 만에 특보구역 세분화」 보도자료 (2026.5.12)

### 재현 방식을 택한 이유

실제 발령 이력은 자료 확보가 번거롭고, 발령 시점의 운영 변수(늦은 발령 등)가 분석에 섞인다. 기준을 직접 재현하면 로직이 투명하고 재현 가능하며, 발표에서도 "그날 발령을 하지 않았다"보다 "특보 기준 자체에 구조적 한계가 있다"는 논지가 더 명확하다.

## 6. 사각지대 정의

폭염특보는 일 단위, 오존은 시간 단위로 변동한다. 이 시간 해상도 불일치에서 두 종류의 사각지대가 발생한다.

**Type A — 일 단위**
```
폭염특보 기준 미충족일
+ 오존 임계값 초과
+ 근무시간대
```
'오늘은 폭염이 아니다'라는 안내로 경계가 해제된 상태

**Type B — 시간 단위**
```
폭염특보일
+ 해당 시각 체감온도 33℃ 미만
+ 오존 임계값 초과
+ 근무시간대
```
'아직 덥지 않다'는 판단으로 방심하나 오존 부하는 최대

## 7. Gate 1 판정 기준 (3주차)

근무시간대 사각지대의 연평균 시간을 기준으로 판정한다.

| 결과 | 조치 |
|---|---|
| 연평균 30시간 이상 | 진행 |
| 10~30시간 | 임계값 조정 후 재판정 |
| 10시간 미만 | PART 1 축소, PART 2 중심으로 전환 |

**원칙** 결과를 확인한 뒤 판정 기준을 변경하지 않는다.
